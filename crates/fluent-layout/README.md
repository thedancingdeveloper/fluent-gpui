# fluent-layout

Pane splitting, dock panels, tab strips, and modal stack for FluentGUI.

Part of [fluent-gpui](https://github.com/thedancingdeveloper/fluent-gpui), a Fluent 2 design system for native Windows and Linux desktop apps, built on Zed's [gpui](https://github.com/zed-industries/zed). Not affiliated with Microsoft.

## Install

Not on crates.io yet. Add it as a git dependency:

```toml
[dependencies]
fluent-layout = { git = "https://github.com/thedancingdeveloper/fluent-gpui" }
```

## Use

See the [repository README](https://github.com/thedancingdeveloper/fluent-gpui#readme) for a minimal app and the `examples/` directory for runnable samples.
